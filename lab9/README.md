# Lab 9 - Banco de dados - Create e Read

Blog com Node.js, Express, EJS e MongoDB, na porta 80.

## Como rodar

Com o MongoDB rodando na máquina:

```
npm install
npm start
```

## Rotas

- `/` abre a página de projetos
- `/blog` mostra todos os posts do banco
- `/cadastrar_post` abre o formulário de novo post
